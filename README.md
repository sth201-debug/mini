# 구구단 광산 ⛏

마인크래프트처럼 땅을 파면서 구구단을 연습하는 브라우저 게임이에요.

## 하는 방법

- `index.html` 파일을 브라우저로 열면 바로 시작돼요. 설치할 것은 없어요.
- 연습할 단(2단~9단)을 고르고 **게임 시작!**을 눌러요.
- 흙, 돌, 나무 블록은 누르기만 하면 캐져요.
- 광석에는 숫자가 적혀 있어요. 그 단의 구구단 문제를 맞히면 광석을 캘 수 있어요.
  - 석탄: 2·3단, 철: 4·5단, 금: 6·7단, 다이아몬드: 8·9단
  - 깊이 내려갈수록 어려운 단의 광석이 많이 나와요.
- 5문제를 연속으로 맞히면 점수가 두 배!
- 틀린 문제는 메뉴(⏸)에서 다시 볼 수 있고, 같은 단 광석을 캘 때 다시 나와요.
- 목표: 다이아몬드 5개 모으기 💎

## 조작

| | 컴퓨터 | 휴대폰·태블릿 |
|---|---|---|
| 이동 | ← → 또는 A D | ◀ ▶ 버튼 |
| 점프 | ↑ W 스페이스 | ▲ 버튼 |
| 캐기 | 블록 클릭 | 블록 터치 |
| 블록 놓기 | 아래 칸에서 블록 고르기(1~5) 뒤 빈 곳 클릭 | 아래 칸 블록 고른 뒤 빈 곳 터치 |
| 메뉴 | Esc | ⏸ 메뉴 |
